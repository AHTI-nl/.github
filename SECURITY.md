# Security policy

Please report suspected vulnerabilities privately to **[security@ahti.nl](mailto:security@ahti.nl)**. Do not disclose vulnerabilities or sensitive information in public GitHub issues, discussions, or pull requests.

Our [Responsible Disclosure policy](https://www.ahti.nl/responsible-disclosure) describes the scope, reporting guidance, and what you can expect from AHTI.

Please include the affected repository, system or URL, a description of the issue, reproduction steps, and its potential impact. Avoid including personal data or other sensitive information unless necessary to demonstrate the vulnerability.
